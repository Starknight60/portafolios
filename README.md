## 💻 Ejecución Local del Portafolio

```bash
# 1. Clonar el repositorio
git clone https://github.com/Starknight60/portafolios.git
cd portafolios

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el portafolio en funcionamiento.
