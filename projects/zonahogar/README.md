# 🏡 ZonaHogar — Radar Inmobiliario de Habitaciones y Anexos Económicos en Venezuela

> **Plataforma PropTech de trato 100% directo con propietarios particulares.** Radar geoespacial interactivo con Google Maps, filtros indispensables para la realidad venezolana (tanque de agua 24/7, planta eléctrica, fibra óptica), calculadora de mudanza & costo total de entrada y contacto inmediato vía WhatsApp sin comisiones inmobiliarias.

---

## 🌟 Propuesta de Valor & Problema Real Resuelto

En Venezuela, conseguir una habitación o anexo económico para estudiantes, trabajadores o parejas es un desafío crítico:
1. **Comisiones abusivas de intermediarios**: Las agencias tradicionales cobran entre 1 y 2 meses de comisión no reembolsable ($150 - $400 USD extras), dinero perdido para el inquilino.
2. **Servicios vitales impredecibles**: Muchos alquileres ocultan problemas graves de racionamiento de agua, cortes eléctricos constantes o falta de internet apto para teletrabajo.
3. **Falta de mapas reales con precios claros**: Los grupos de Facebook o portales clasificados están llenos de publicaciones sin fotos reales, sin precio transparente en $ USD o con ubicaciones inexactas.

**ZonaHogar** soluciona esto de raíz:
- **0% Comisiones / Trato 100% Directo**: Conecta al interesado directamente con el dueño por WhatsApp, con mensaje pre-estructurado y respetuoso.
- **Radar Panorámico en Google Maps**: Pines interactivos con precios en $ USD, halos de proximidad y rutas a pie a estaciones de Metro o paradas clave.
- **Filtros de Supervivencia Real**:
  - 🚰 Tanque propio con litros exactos y bombeo continuo.
  - ⚡ Planta eléctrica o circuitos sin cortes.
  - 🌐 Fibra óptica con proveedor y velocidad real (NetUno, Fibex, Airtek).
  - 🎓 Acepta estudiantes / 👫 Parejas / 🐾 Mascotas / 🔑 Llaves independientes.
- **Calculadora de Mudanza & Costo Total de Entrada**: Calcula el efectivo exacto en mano (primer mes + depósito reembolsable + redacción + flete) y grafica el ahorro directo vs. inmobiliarias.
- **Publicación Gratuita de Particulares**: Formulario ágil para que dueños publiquen en 1 minuto.

## 🛠️ Stack Tecnológico

- **Frontend**: Next.js 16 (App Router), React 19, TypeScript.
- **Mapas & Geoespacial**: Leaflet 1.9.4, React-Leaflet, Google Maps Layers (Calles y Satelital híbrido).
- **Diseño & UI**: Tailwind CSS 4, Lucide React, Glassmorphism moderno y paleta obsidian/ámbar/esmeralda.
- **Audio Feedback**: Web Audio API nativo con tonos tácticos y chimes de confirmación.
- **Cero Dependencias Externas Innecesarias**: 100% responsive en smartphones, tablets y monitores ultra-wide.

## 🚀 Instalación y Ejecución Local

```bash

git clone https://github.com/Starknight60/portafolios.git
cd portafolios/projects/zonahogar

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# Abrir en el navegador:
http://localhost:3000 (o el puerto configurado)
```
